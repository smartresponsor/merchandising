# Merchandising

Merchandising owns storefront composition: what sections appear, in what order, for which surface, and through which source-backed items.

It does not own product, category, project, vendor, user, payment, or shipping truth. It composes UI-ready merchandising surfaces from source contracts and emits a stable output contract for Bridging and Interfacing.

Canonical package name: `merchandising/merch`.

Canonical namespace: `App\Merchandising`.

Canonical storage/config prefix: `merch_`.
